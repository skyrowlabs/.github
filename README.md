# skyrowlabs/.github

GitHub renders the [skyrowlabs](https://github.com/skyrowlabs) org page from
`profile/README.md` in this repo. That file is a **mirror**: its home is
`profile/README.md` in the private `skyrowlabs/skyrowlabs.com` repo, and a
workflow there copies it here on every change. Edits made here are overwritten.
